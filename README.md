# Nashri AI

A modern AI creative platform inspired by AI art communities and design tools.

## Features

- **AI Image Generator** - Create stunning images with AI
- **AI Character Creator** - Design unique characters
- **Gallery & Projects** - Organize your creative works
- **Community** - Connect with other creators
- **Premium Subscriptions** - Flexible pricing plans
- **Credit System** - Track and manage your creative credits

## Getting Started

### Prerequisites
- Node.js 16+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Lucide Icons
